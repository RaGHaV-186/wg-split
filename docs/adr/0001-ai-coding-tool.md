# ADR-0001: AI coding tool

## Context
20-week top-down track: AI agents write most code, I own decisions and review.
Needs: plan before code, project rules (CLAUDE.md). Budget €45/month total.
New to coding agents.

## Options
- Claude Code (Pro plan, already paid)
- Cursor Pro ($20/month, best visual diffs)
- GitHub Copilot (free for students if sign-ups reopen, else $10/month)

## Decision
Claude Code. Fits budget and curriculum (hooks, subagents, headless CI are planned around it).

## Consequences
+ No extra cost; matches the track
- No Cursor visual diffs (mitigation: VS Code-based editor)
- Chat and Claude Code share one usage limit
Two-way door for the subscription; stickier as CLAUDE.md and hooks grow. Revisit Day 69.
